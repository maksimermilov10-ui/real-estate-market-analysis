# Анализ рынка недвижимости Санкт-Петербурга и Ленинградской области

## Задача

Агентство недвижимости из Петрозаводска планирует выйти на рынок Санкт-Петербурга и Ленинградской области. Нужно проанализировать архив объявлений сервиса «Яндекс Недвижимость», чтобы:

1. определить самые перспективные сегменты недвижимости по времени активности объявлений;
2. выявить сезонные тенденции спроса и предложения для планирования маркетинговых кампаний и сроков выхода на рынок.

## Данные

Схема `real_estate` в PostgreSQL:

| Таблица | Описание |
|---|---|
| `advertisement` | объявления: `id`, `first_day_exposition` (дата подачи), `days_exposition` (срок активности, дней), `last_price` |
| `flats` | квартиры: `id`, `city_id`, `type_id`, `total_area`, `rooms`, `ceiling_height`, `floors_total`, `living_area`, `floor`, `is_apartment`, `open_plan`, `kitchen_area`, `balcony`, `airports_nearest`, `parks_around3000`, `ponds_around3000` |
| `city` | `city_id`, `city` |
| `type` | `type_id`, `type` (тип населённого пункта) |

## Стек

## Ход работы

1. **Знакомство с данными** — подключение к БД через DBeaver, базовые метрики (период выгрузки, доля СПб, распределение по типам населённых пунктов, цена за м²).
2. **Задача 1. Время активности объявлений** — сегментация объявлений СПб и Ленобласти по срокам экспозиции (1–30 / 31–90 / 91–180 / 181+ дней) с очисткой выбросов по перцентилям (1-й и 99-й) и сравнением цены, площади, числа комнат/балконов, высоты потолков и этажа между сегментами и регионами.
3. **Задача 2. Сезонность** — помесячная динамика публикаций и снятий объявлений (2015–2018), средней цены за м² и средней площади, с расчётом корреляции между числом публикаций и снятий.
4. **Дашборд в DataLens** — доработка существующего дашборда агентства новыми элементами (визуальная часть проверяется отдельно ревьюером, в репозитории не хранится).

## Ключевые выводы

- В обоих регионах доминируют долгие продажи (более полугода) — 31–33% объявлений; быстрые продажи (1–30 дней) — только 12–15%.
- СПб примерно в 1,5 раза дороже Ленобласти (110–115 тыс. руб./м² против 70–71 тыс.) — разница почти не зависит от срока активности.
- Более крупные квартиры (60+ м²) продаются заметно дольше в обоих регионах.
- Пик активности и по публикациям, и по снятиям — сентябрь–ноябрь; провал по публикациям — январь.
- Корреляция между числом публикаций и снятий по месяцам — около 0.61 (заметная, но не идеальная связь), с лагом 1–3 месяца между выставлением объекта и продажей.
